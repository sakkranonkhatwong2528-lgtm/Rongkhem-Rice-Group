# Rongkhem-Smart-Village
ระบบบริหารจัดการหมู่บ้านอัจฉริยะ บ้านร่องเข็ม หมู่ที่ 6[cite: 1]

## เกี่ยวกับระบบ
สมาชิกระบบกลุ่มข้าวสารบ้านร่องเข็ม หมู่ที่ 6[cite: 1] จัดทำขึ้นเพื่อใช้ในการบริหารจัดการข้อมูลสมาชิก ข้อมูลคลังข้าว และระบบงานต่างๆ ของหมู่บ้านอัจฉริยะ รองรับการทำงานทั้งบนคอมพิวเตอร์และมือถือผ่านระบบ Cloud Database (Firebase Firestore) พร้อมระบบจำกัดสิทธิ์การใช้งาน (สมาชิกดูข้อมูลได้ / แอดมินจัดการระบบ)

## โครงสร้างระบบหลัก
- **ระบบสมาชิก (`members.js` / `members.html`):** จัดการรายชื่อครัวเรือนและสมาชิกกลุ่มข้าว
- **ระบบคลังข้อมูลและฐานข้อมูล (`database.js`):** เชื่อมต่อ Firebase สำหรับบันทึกข้อมูลแบบถาวร
- **ระบบแจ้งไว้อาลัย/งานศพ (`funeral.js` / `funeral.html`):** บันทึกและอัปเดตข้อมูลข่าวสารภายในชุมชน
